Новый проект игры «Лила» по книге Хариша Джохари. Старый v1 (/var/www/lila/app) не трогаем.
Полные решения и контекст: `DOCS/decisions.md`. Серверные заметки: `DOCS/SERVER.md` (в .gitignore, локально).

## Статус
- **M0 закрыт** на сервере (`~/lila/lila`): ядро правил, 19 тестов зелёные, tsc чистый, сборка OK.
- **Идёт M1**: доска с цифрами, анимация фишки (pace.ts), свиток, дым/мерцание.
- ⚠️ Файлы в этом репозитории — каноническая копия кода с сервера. На сервере pace.ts уже создаётся вашей командой; здесь сверим с дампом (`cat /tmp/lila-dump.txt`), когда пришлёте его.

```

src/anim/pace.ts    темп анимаций M1 (подобран по симуляции 50k партий)
DOCS/decisions.md   все зафиксированные решения (продукт, правила, архитектура, визуал)
```

## Правила (кратко, канон johari-ru-v1)
Вход только по 6 (68→1→6). Любая 6 — повторный бросок. Ровно 3 шестёрки — сгорают, возврат + 4-й бросок. 4+ шестёрок — сумма, один ход. Перелёт >72 — ход не исполняется. Финиш точно на 68. Серии разрешаются одним ходом в конце (resolve: "series").

## Запуск на VPS (из ~/lila/lila)
```bash
npm install
npx tsc --noEmit && npx vitest run   # проверки
npm run sim                          # Монте-Карло
npm run build                        # dist/ для nginx
```
