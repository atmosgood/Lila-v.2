=== Ключевые решения того чата ===

АРХИТЕКТУРА (слои): PRESENTATION → CHOREOGRAPHER (очередь событий→сцен) → APP/FLOW
(иерархическая машина состояний) → GAME CORE (чистые функции, детерминированный RNG
seed, RuleSet JSON) → CONTENT DATA (72 клетки, переходы, i18n — всё данными) →
PERSISTENCE (event sourcing: дневник, восстановление партии, IndexedDB офлайн).
Два времени: логика мгновенна, анимация играется отдельно; пропуск/ускорение не
ломают правила.

ИСТОРИЯ ХОДОВ: пользователю не показывается (ему нужен ответ на вопрос), но журнал
нужен внутренне: ведущий строит ответ по всей цепочке клеток партии; сохранение
незавершённой партии.

ВИЗУАЛ: статичные арты + анимация только кубика, фишки, змей/стрел, свитка. Дым и
мерцание светильников — кодом на canvas, без видео. Окна — разворачивающийся свиток.
На клетках доски ТОЛЬКО цифры (+ значки змеи/стрелы в углу); миниатюры 72 клеток —
иллюстрации в окне-потхи, НЕ фон клеток (клетка ~43px на телефоне, сюжет не читается).
Цифра в латунном медальоне, контраст ≥4.5:1, у каждого ряда свой тон, режим «крупные
цифры». При попадании на змею/стрелу: фишка встаёт → свиток с артом кобры / лука со
змеями → подпись перехода → «Принять» → скольжение по траектории → окно клетки
назначения + чат. Рамки окон — одна картинка + 9-slice (border-image); кнопки —
3-slice, состояния (hover/active/disabled) кодом; свиток: торец стержня картинкой +
mirror, бумага бесшовно по вертикали. prefers-reduced-motion обязателен.

ПРАВИЛА (канон johari-ru-v1, глава 1 книги; спорные вопросы решены «по умолчанию»,
переключателей пользователю нет):
- Доска 9×8=72, змейкой снизу вверх (1–9 слева направо, 10–18 справа налево…).
- Старт всех фишек на 68 «Космическое Сознание». Вход только по 6: фишка на 1
  «Рождение», оттуда 6 шагов → клетка 6.
- Любая 6 — повторный бросок, на любой стадии (даже когда ход с ней невозможен).
- Ровно 3 шестёрки подряд + другое число: серия сгорает, возврат на клетку ДО серии
  (при входе — на 1), ход только на 4-й бросок.
- 4+ шестёрок: сумма всех очков серии, один ход от клетки до серии.
- Серии разрешаются ОДНИМ ходом в конце (resolve "series"; "perRoll" не используем);
  змея/стрела срабатывают автоматически на итоговой клетке хода.
- Перелёт >72: ход не исполняется. С 69 годятся 1–3, с 70 — 1–2, с 71 — только 1.
- Победа ТОЧНО на 68 (ходом или стрелой 54→68). С 67–68 на 68 шагнуть нельзя: ждём
  змею 72→51, оттуда 3 → 54 → стрела → 68.
- Опечатка перевода («с 71 единица ведёт на 68») — делаем по геометрии: 71+1=72→змея→51.
- Стрелы: 10→23, 17→69, 20→32, 22→60, 27→41, 28→50, 37→66, 45→67, 46→62, 54→68.
- Змеи: 12→8, 16→4, 24→7, 29→6, 44→9, 52→35, 55→3, 61→13, 63→2, 72→51.
- Названия клеток по главе 2: 6 — «Заблуждение (моха)», 29 — «Отсутствие религиозности
  (адхарма)», 31 — «План святости (якша-лока)», 47 — «План нейтральности». Исправлять
  артефакты OCR («ъ» вместо «ь»).
- АП: тексты Джохари и рисунки доски защищены (© 1980, 1993 H. Johari; перевод ©
  «София», 1999) — в приложении собственные толкования по смыслу.
- Книга советует записывать путь фишки → подтверждает event sourcing и дневник.
